How to Create Users

  1. 1
    Access Keycloak Admin Console

    Click "Open Keycloak Admin" button above and log in with your organization admin credentials.

  2. 2
    Navigate to Users

    In the left sidebar, click on "Users" to see the list of existing users.

  3. 3
    Create New User

    Click "Create user" and fill in: Username, Email, First name, Last name. Toggle "Email verified" to ON.

  4. 4
    Set Password

    Go to "Credentials" tab, click "Set password", enter password, set "Temporary" to OFF.

  5. 5
    Assign to Organization

    Go to "Groups" tab, click "Join Group", select Organization/Users

  6. 6
    Assign Role

    Go to "Role mappings" tab, click "Assign role", select "USER" role.

  7. 7
    Set Organization Attributes

    Go to "Attributes" tab, add: organization = Organization, orgId = org-id

Tip: New users can immediately log in at /login with their username and password to start uploading files.
